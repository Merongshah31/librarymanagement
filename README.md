# librarymanagement
The Management of Budiman Private School is planning to design and implement a Budiman Library Management System.
The system will efficiently organize book and member information, handle borrowing and returning processes, and provide functionalities such as book registration, member management, and inventory management using structured programming techniques. The system will utilize linked lists, queues, sorting techniques, and searching techniques for efficient data handling. All data will be stored in simple text files to ensure data persistence.
